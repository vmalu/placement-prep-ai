# Placement Prep & Core CS (Python)

Daily problem-solving repository covering Data Structures, Algorithms, and IT placement coding patterns.

- **Day 1 (`day1_palindrome.py`):** Palindrome Check (String Slicing & Case Normalization)
- **Day 2 (`day2_char_frequency.py`):** First Non-Repeating Character (Hash Map Frequency Count)
- **Day 3 (`day3_second_largest.py`):** Second Largest Element in Array (O(N) Single Pass)
- **Day 4 (`day4_move_zeroes.py`):** Move Zeroes to End In-Place (Two-Pointer Partitioning)
- **Day 5 (`day5_valid_anagram.py`):** Valid Anagram Check (Dictionary Frequency Matching)
- **Day 6 (`day6_missing_number.py`):** Missing Number in Sequence (Math Formula & Bitwise XOR)
- **Day 7 (`day7_two_sum.py`):** Two Sum Problem (O(N) Hash Map Lookup)

## Week 2: Linear Data Structures (Stacks & Linked Lists)
